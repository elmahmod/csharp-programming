## 🟣 3. Types of .NET

The instructor mentioned three main names, but they represent different technologies and versions of .NET.

### 1. .NET Core (Now Called .NET)

A modern, cross-platform development platform.

It can run many types of applications on:

- Windows
- Linux
- macOS

**Example:** You can write a Console application in C# on Windows and run it on Linux as well, as long as it does not depend on Windows-specific features.

Important note: After `.NET Core 3.1`, the name changed to `.NET 5`, and later versions continued using the name `.NET`, such as `.NET 8` and `.NET 10`.

### 2. .NET Framework

The original and older version of .NET, which runs on **Windows only**.

It is used for applications such as:

- Windows Forms
- WPF
- Classic ASP.NET
- Windows Services

**Example:** A student management application with buttons, windows, and tables built using Windows Forms.

### 3. Xamarin / Mono

These technologies were used to support running and developing .NET applications on other operating systems, especially mobile devices.

- **Mono:** An alternative implementation of .NET that runs on multiple operating systems.
- **Xamarin:** A technology that allowed developers to create Android and iOS applications using C#.

However, Xamarin officially reached the end of support in May 2024, and **.NET MAUI** replaced Xamarin.Forms for developing cross-platform applications.

## 🟠 4. Difference Between .NET and .NET Framework

| Comparison | Modern .NET | .NET Framework |
|---|---|---|
| Operating System | Windows / Linux / macOS | Windows only |
| Modern or Old? | Modern and continuously evolving | Older and maintained |
| Console Apps | ✅ | ✅ |
| Web Apps | ✅ | ✅ |
| Windows Forms | ✅ | ✅ |
| WPF | ✅ | ✅ |

**Important:** Although modern .NET is cross-platform, Windows Forms and WPF only run on Windows, even when using modern .NET.
