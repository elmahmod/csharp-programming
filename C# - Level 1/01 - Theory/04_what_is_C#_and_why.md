# What Is C#?

**C# (pronounced "C sharp")** is a general-purpose, high-level, object-oriented programming language developed by Microsoft.

- The first version of C# was released in **2002**.
- **C# 11** was released in **November 2022** (the latest version at the time of the course slides).
- C# is widely used to develop desktop and web applications.
- C# has syntax influenced by C and C++, and it is also syntactically similar to Java.

## Why Is It Called C#?

The name **"C sharp"** was inspired by musical notation.

In music, the sharp symbol (**♯**) raises a written note by **one semitone**. The name reflects the idea of an evolution of the C-family languages.

## What Can We Do with C#?

C# can be used to build many types of applications supported by **.NET**, including:

- 🖥️ **Desktop Applications**
- 🌐 **Web Applications**
- ☁️ **Cloud Applications**
- 📱 **Mobile Applications**
- 🎮 **Games**
- 🔌 **Internet of Things (IoT)**
- 🧠 **Artificial Intelligence (AI) Applications**

## Main Features of C#

1. **Modern:** C# is a modern, powerful language that helps developers build robust applications efficiently.
2. **Simple:** Its syntax is relatively easy to read and understand, especially for developers familiar with languages such as Java.
3. **Type-Safe:** C# checks types to help prevent the incorrect use of values and reduce certain programming errors.
4. **Object-Oriented:** C# supports classes, objects, inheritance, polymorphism, and other object-oriented concepts.
5. **High-Level:** Its programming constructs are designed to be understandable and convenient for developers.
6. **Large Community:** C# has a large developer community, making it easier to find learning resources, solutions, and support.

---

## Summary

**C#** is a modern, general-purpose, object-oriented, high-level, and type-safe programming language. Together with **.NET**, it can be used to develop many different kinds of applications.
