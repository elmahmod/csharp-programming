
# 💻 What Can We Build Using .NET?

The image presented by the instructor explains **the different programming fields in which we can use the .NET platform**.

As we learned earlier, **.NET is a Development Platform** created by Microsoft. It provides developers with the tools and libraries needed to build different types of applications using programming languages such as C#.

.NET allows us to work in **7 main fields**.

## 1. 🖥️ Desktop Applications

These are programs that we install and run on a computer.

**Examples:**
- Student Management System.
- Accounting Software.
- Inventory Management System.

**Technologies Used:**
- `Windows Forms`
- `WPF`
- `.NET MAUI`

For example, you can create a Windows Forms application using C# that contains buttons (Buttons) and input fields (TextBoxes).

## 2. 🌐 Web Applications

These are applications that we use through web browsers such as Chrome or Firefox.

**Examples:**
- E-commerce websites.
- Appointment Booking Websites.
- University Management Systems.

**Technologies Used:**
- `ASP.NET Core`
- `Blazor`

For example, you can create a website that allows users to register accounts and log in.

## 3. ☁️ Cloud Applications

These are applications and services that depend on cloud servers to run their functions or store data.

**Examples:**
- A service for storing user data.
- A system for processing thousands of requests.
- A notification service.

**Technologies Used:**
- `ASP.NET Core`
- `Azure Functions`

For example, your application's server can run on Microsoft Azure instead of running on your personal computer.

## 4. 📱 Mobile Applications

We can use .NET to develop applications that run on Android and iOS.

**Examples:**
- Task Management Application.
- Expense Tracking Application.
- Notes Application.

**Technology Used:**
- `.NET MAUI`

It is the modern technology that replaced Xamarin.Forms.

## 5. 🎮 Gaming

We can use C# to develop games.

**Examples:**
- Two-dimensional games (2D).
- Three-dimensional games (3D).
- Mobile games.

**Technology Used:**
- `Unity`

For example, using C#, you can program character movement, jumping, and collisions between objects.

**Note:** Unity uses C# and a .NET-compatible runtime, but it is not a framework within modern .NET in the same way as ASP.NET Core.

## 6. 🔌 IoT — Internet of Things

IoT stands for **Internet of Things**.

It is a field that involves connecting electronic devices to the internet to collect data or control them.

**Examples:**
- Smart Home Devices.
- Temperature Sensors.
- Smart Irrigation Systems.

**Technologies Used:**
- `.NET IoT Libraries`
- `System.Device.Gpio`

For example, you can program a device that reads the room temperature and sends the data to an application.

## 7. 🧠 AI — Artificial Intelligence

AI stands for **Artificial Intelligence**.

We can use .NET to develop applications that use Artificial Intelligence and Machine Learning.

**Examples:**
- Spam Detection.
- House Price Prediction.
- Image Classification.

**Technologies Used:**
- `ML.NET`
- `ONNX Runtime`

For example, you can train a Machine Learning model using ML.NET to classify messages as Spam or Not Spam.

---

## 🔍 How Can .NET Build All These Applications?

Because it provides a common foundation that includes:

1. **Programming Languages:** Such as C#.
2. **Libraries:** Ready-to-use libraries.
3. **Runtime:** An environment for running applications.
4. **Frameworks:** Frameworks that help build specific types of applications.

Then, you choose the appropriate technology depending on the type of application you want to develop.

## 🎯 Summary

| Field | Technology Used |
|---|---|
| 🖥️ Desktop | Windows Forms / WPF |
| 🌐 Web | ASP.NET Core |
| ☁️ Cloud | ASP.NET Core / Azure |
| 📱 Mobile | .NET MAUI |
| 🎮 Gaming | Unity + C# |
| 🔌 IoT | .NET IoT |
| 🧠 AI | ML.NET |

**The Most Important Concept to Remember:**

.NET is not only designed for developing Windows applications. It is a platform that can be used to develop applications in many different fields.

This does not mean that you need to learn all these technologies. You only need to learn **C# and .NET Fundamentals** first, and then choose the field you want to specialize in.
