
# .NET Framework Class Library (FCL)

The **.NET Framework Class Library (FCL)** is a collection of classes, namespaces, interfaces, and value types used to develop .NET applications.

It contains thousands of classes that support the following functionality:

- **Data Types:** Base and user-defined data types.
- **Exception Handling:** Handling exceptions.
- **Input/Output (I/O):** File and stream operations.
- **System Communication:** Communication with the underlying system.
- **Data Access:** Accessing and managing data.
- **Windows Applications:** Creating Windows-based GUI applications.
- **Web Applications:** Creating web client and server applications.
- **Web Services:** Creating web services.

## Libraries and Namespaces

Examples shown in the .NET Framework Class Library diagram:

- `System.Web`
- `System.Windows.Forms`
- `System.Drawing`
- `System.Data`
- `System.Xml`
- `System` — Collections, I/O, Security, Runtime, Networking, Diagnostics, Reflection, Text, Threading, and more.
