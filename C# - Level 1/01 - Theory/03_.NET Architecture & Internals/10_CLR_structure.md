# .NET CLR Structure

The **Common Language Runtime (CLR)** contains several components, each responsible for a specific task while a .NET application runs.

1. **Base Class Library Support:** Supports the use of .NET's basic libraries and classes.
2. **Thread Support:** Manages the execution of multiple tasks using threads.
3. **COM Marshaler:** Helps .NET applications communicate and exchange data with COM components.
4. **Type Checker:** Checks data types and verifies their safety according to CLR rules.
5. **Exception Manager (Handler):** Handles exceptions that occur while the application is running.
6. **Security Engine:** Helps enforce security rules and restrictions during execution.
7. **Debug Engine:** Helps developers trace program execution, find errors, and fix them.
8. **IL Compilers (JIT):** Converts IL instructions into native machine code for the CPU to execute.
9. **Code Manager:** Manages information about code during program execution.
10. **Garbage Collector (GC):** Reclaims memory from objects that the program can no longer access.
11. **Class Loader:** Loads the classes required by the application at runtime.

---

**Summary:** These components work together inside the CLR to help execute and manage .NET applications.
